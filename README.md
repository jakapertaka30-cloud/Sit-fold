# SIT & FOLD WEBSITE

Website promosi produk kursi lipat multifungsi Sit & Fold.

## Struktur file
- index.html — struktur dan konten website
- style.js — styling responsif
- app.js — navigasi dan interaksi
- assets/sit-fold-product.png — foto produk
- assets/sit-fold-lifestyle.png — foto lifestyle
- assets/sit-fold-promo.mp4 — video promosi

## Menjalankan
Buka index.html melalui browser setelah seluruh file dan folder assets tersedia.

## GitHub Pages
Buka Settings > Pages, pilih Deploy from a branch, pilih branch main dan folder /(root), lalu Save. Website statis ini tidak memerlukan proses build.

Catatan: formulir kontak menggunakan mailto untuk menyiapkan email di perangkat pengunjung, bukan menyimpan pesan ke database.
